# AWKUM Student Portal (Mobile Webpage)

A responsive, mobile-first clone of the Abdul Wali Khan University Mardan (AWKUM) student portal (`eservices.awkum.edu.pk`).

## 📱 Features
- **Mobile-First Layout**: Optimized for mobile devices and desktop browsers with device preview frame.
- **Header & Navigation**: Dark top bar with the official AWKUM crest, primary blue navbar with collapsible sidebar drawer.
- **Calligraphy & Dynamic Clock**: Elegant Arabic Nastaliq greeting and real-time clock.
- **Urgent Notification Banner**: Alert box for student notifications.
- **Activity & Course Management**: Tab switcher (`Activity`, `Result`, `Fee History`), Assigned Courses table with interactive course actions.
- **Interactive To Do & Single Slip**: Online payment guides and official E-Registration single slip document generator.
- **Student Profile**: Student academic details with expandable information.
- **Suggested To You & Completed Tasks**: List items with synchronized blinking indicators.

## 🚀 Getting Started
Simply clone the repository and open `index.html` in any web browser:

```bash
git clone <repository-url>
cd IMS
# Open index.html in your browser
```
